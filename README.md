# The Designer’s Menu — AVIF संस्करण

इस पैकेज में GitHub Pages पर लगाने के लिए तैयार इंटरैक्टिव मैगज़ीन है। इसमें 85 क्रमांकित चित्र, अलग मुखपृष्ठ और बैक कवर, पुरानी सूची के 103 तथा नई सूची के सभी 171 लिंक-एंट्री हैं। नई सूची के 15 विषय, विवरण, नोट, कीमत और स्रोत में दिए गए स्टार सुरक्षित हैं। कुछ वेबसाइटें दोनों सूचियों में आती हैं; उन्हें हटाया नहीं गया है। मैगज़ीन में कुल 181 पृष्ठ हैं।

## GitHub Pages पर लगाएँ

1. ZIP को extract करें। फ़ोल्डर के अंदर सीधे `index.html`, `assets/`, `licenses/` और `.nojekyll` मिलेंगे।
2. अपने GitHub repository की मुख्य/root जगह में **इन फ़ाइलों और फ़ोल्डरों का पूरा अंदरूनी भाग** अपलोड करें। पूरा ZIP या उसे घेरने वाला अतिरिक्त फ़ोल्डर root में न रखें। `assets/` की सभी फ़ाइलें `index.html` के साथ रहनी चाहिए। यदि आपका repository पहले से है, तो बदलाव अपलोड करने से पहले उसका बैकअप लें।
3. GitHub में **Settings → Pages → Build and deployment** खोलें। Source में **Deploy from a branch**, branch में `main` (या आपकी प्रकाशन branch) और folder में **/(root)** चुनकर Save करें।
4. Pages के उसी Settings पृष्ठ पर साइट का पता दिखाई देने पर उसे खोलें। पहली बार publish होने में कुछ समय लग सकता है।

## ऑफ़लाइन पढ़ें

ZIP extract करने के बाद `index.html` को आधुनिक Chrome, Edge, Firefox या Safari में खोलें। `assets/` फ़ोल्डर साथ रहे तो मैगज़ीन और चित्र बिना इंटरनेट चलेंगे। बाहरी websites के लिंक खोलने के लिए इंटरनेट चाहिए। अलग single-file ऑफ़लाइन HTML संस्करण भी उपलब्ध है, जिसमें चित्र पहले से समाहित हैं।

## क्या सुरक्षित रखा गया है

- चुने हुए चित्र 74 और 75 क्रमशः वास्तविक पृष्ठ 104 और 105 पर हैं; सारे 85 चित्र एक-एक पृष्ठ पर हैं।
- शुरुआत और अंत के दोनों टेक्स्ट पृष्ठ नीले हैं; महिला–मयूर बैक कवर अलग और सबसे अंत में है। चित्रों के शीर्षकों के पीछे कोई अपारदर्शी पट्टी नहीं है।
- Search, पुराने और नए सूची-विषय, पन्ना पलटना, मोबाइल swipe और चित्र zoom उपलब्ध हैं।
- सभी 87 चित्र-फ़ाइलें (85 चित्र और दो कवर) AVIF हैं। पैकेज में SVG या PNG artwork नहीं है। Workspace में स्रोत PNG फ़ाइलें अलग से सुरक्षित हैं।
- AVIF संपीड़न lossy है: उच्च zoom पर raster के मूल resolution की सीमा होगी; इसे lossless या vector नहीं माना जाना चाहिए। चित्र 84 पहले स्वीकृत ज्यामितीय डिज़ाइन की 2× raster rendering से बनाया गया है।
- `assets/manifest-avif.json` में artwork source, dimensions और SHA-256 hashes हैं। वेबसाइटों के नाम, विवरण और कीमतें संलग्न स्रोत के अनुसार हैं; उपलब्धता और कीमतें समय के साथ बदल सकती हैं।

फ़ॉन्टों की लाइसेंस फ़ाइलें `licenses/` में और HTML के भीतर हैं।
